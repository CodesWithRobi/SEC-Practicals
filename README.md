A centralized monolithic repository containing all laboratory experiments, assignments, and coursework projects completed during my Computer Science studies at Saveetha Engineering College (SEC). 

## 📂 Directory Structure & Coursework

The repository is clustered into course-specific directories. Below is an overview of the practicals and concepts covered in each module:

### 🧠 AI, Machine Learning & Neural Networks
* **`Artificial-Intelligence/`**: Implementations of classic AI search algorithms (A*, BFS, DFS, Minimax, Hill Climbing) and PEAS agent models.
* **`Machine-Learning/`**: Supervised and unsupervised learning models using `scikit-learn`, `numpy`, and `pandas` (Linear/Logistic Regression, K-Means, SVM).
* **`Neural-Networks/`**: Perceptron implementation, Multi-Layer Perceptron (MLP) with Backpropagation, and Kaggle dataset preprocessing.

### ☕ Data Structures & Algorithms
* **`Data-Structures-Java/`**: Extensive Java implementations covering arrays, linked lists, stacks, queues, trees (BST), graphs (Dijkstra's), and Java Collections Framework (HashMaps, TreeSets).

### 🔐 Cybersecurity & Cryptography
* **`Cryptography/`**: C implementations of classical ciphers (Caesar, Playfair, Hill, Vigenere, Rail Fence) and modern cryptographic concepts.
* **`Ethical-Hacking/`**: Scripts and lab records covering Information Gathering (Nmap, Whois), Metasploit exploitation, SQL Injection, and backdoor creation.

### 💻 Systems & Architecture
* **`Operating-Systems/`**: Linux shell scripting, Process API (fork, wait, exec), File I/O, System locking, and Inter-Process Communication (Pipes, Semaphores, Message Queues, Shared Memory).
* **`Computer-Networks/`**: TCP/UDP Socket programming in Python, HTTP webpage fetching, File transfer protocols, and sliding window protocol simulations.
* **`Digital-Electronics/`**: Verilog HDL code and Quartus project files for logic gates, Flip-Flops (D, JK, SR, T), Shift Registers, and Synchronous Up-Counters.
* **`Microprocessors-Embedded/`**: 8086 Assembly Language Programming (ALP) basics and ARM Cortex interfacing simulations using Proteus (LCD, Keypad, Interrupts).

### 🌐 Cloud, IoT & Web
* **`Cloud-Computing/`**: Cloud deployment models, case studies, and PBS encryption time calculations.
* **`Internet-of-Things/`**: Arduino and ESP32 programming for sensor integrations (ultrasonic, soil moisture) and data uploading to the ThingSpeak cloud.
* **`Web-Data-Mining/`**: Link analysis, Boolean models, Vector Space models, and web scraping scripts.

### 🛠️ Additional Engineering Topics
* **`Compiler-Design/`**: Lexical analysis and compiler construction basics.
* **`Prompt-Engineering/`**: Experimentation with AI prompting techniques and cross-platform interactions.
* **`Engineering-Design/`**: 3D solid modeling and orthographic projections.

## 🛠️ Tech Stack & Tools Used

* **Languages:** Java, Python, C, Bash, Verilog, 8086 Assembly.
* **Tools & Environments:** Linux CLI, Git, Quartus Prime, Proteus Design Suite, Cisco Packet Tracer, Arduino IDE, Jupyter Notebooks.
* **Libraries/Frameworks:** Scikit-Learn, Pandas, NumPy.
